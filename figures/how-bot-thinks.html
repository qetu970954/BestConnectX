01

PUCT is the steering rule inside MCTS.

MCTS builds a tree of possible futures. PUCT chooses which branch deserves the next look: promising moves, but also moves we have not explored enough.

02

One board, two kinds of advice.

Policy: “Where should we look?” Value: “How good is this position for the player to move?” Neither is a proof of a win.

04

Bigger brain, deeper search, faster pipeline: different knobs.

Starting values for this machine — not a claim of optimal strength
KnobStarting valueWhat it actually changes
Channels C · width64Feature maps per cell. Double C → roughly 4× dense-convolution work, not 2×.
Residual blocks B · depth6More stacked transformations. Double B → roughly 2× body work.
Board edge · spatial size1515×15 → 19×19 means 225 → 361 cells. Full attention compares cell pairs: its pair work grows with the fourth power of the edge.
Simulations · search effort64 in self-playMore futures explored per placement. Does not add model layers; live play is also limited by thinking time.
Workers / parallel games · throughput6 / 64CPU threads / independent game roots. Helps feed inference batches, not make a wider neural network.
Learning batch / learning rate128 / 0.001Samples per optimizer update / update size. Changes learning and memory use, not the model's shape.

Wider is not automatically stronger.

A slower model may get fewer searches in the same thinking time. Compare complete bots at equal time, not just parameter counts.

Attention sees farther — at a price.

Convolutions build local patterns; attention connects distant cells directly. Its strength benefit is still an experiment here.

05

Learn the search's advice and the game's real result.

The model learns numbers, not new game rules. Generate games and update weights in alternating phases.

The experiment worth running

Train residual, pooled, and attention models in separate runs. Compare them under the same rules and thinking time. Measure strength per training hour, not GPU usage.

The Connect6 detail that matters

One placement is not always one turn. The same player can place two stones; value signs must follow the player, not blindly alternate after each stone.

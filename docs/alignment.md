# 歷史需求：可設定棋規的正方形連棋訓練

> 歷史需求紀錄。現行已核准範圍見[移植共識](migration-requirements.zh-TW.md)；舊預設、永久自我對弈棋譜及 Python 推論等要求不再適用。原子保存、續訓、磁碟上限及證明完整性仍保留。

本文件以使用者最後確認的需求為準，取代早先「只做固定 9×9 五子棋試跑」與「瀏覽器啟動訓練」的方向。使用者已同意刪除舊固定六子棋 trainer／UI，並進一步要求清除既有棋譜、權重與其他生成產物，以全新 framework 交付；此明確清除要求取代先前保留本機歷史資料的決定。舊程式由 Git 歷史保存，不為舊 checkpoint 加遷移層。使用者要求若瓶頸確在原生搜尋，才移植 C++，不在未量測前整套重寫。

## 棋規與 CLI

- 訓練入口：`python train.py --connect 5 --board_size "9*9" --stones_per_turn 1 --starter-stones 1`。
- 支援自由五子棋、Connect6 式回合及其他正方形棋盤大小；標準六子棋使用 `--connect 6 --board_size "19*19" --stones_per_turn 2 --starter-stones 1`。
- **使用者已撤回長方形棋盤需求。只接受 N×N，拒絕 `9*13`。** 正方形保留四種旋轉 × 是否反射的八種資料增強。
- 黑棋先行；`starter-stones` 表示黑棋開局回合的棋子數；之後雙方每回合依 `stones_per_turn` 放子。獲勝立即停止，包括兩子回合的第一子。
- 橫、直、斜連成 `connect` 子或更多即勝；無禁手、無交換開局。棋盤填滿而無勝者為和棋。
- 工程選擇：棋盤邊長 2..25、連線長度 2..N、開局與一般回合各支援 1 或 2 子。無效設定明確拒絕，不默默降級。
- 不同棋規使用獨立資料目錄；續訓必須驗證棋規，不接受舊固定六子棋格式的存檔。

## 訓練與保存

- 目標是持續提高實際棋力，不只是產生下降的 loss。使用原創 AlphaZero 式策略／價值網路、自我對弈及適用當前棋規的 TSS。
- TSS 與獨立證明驗證接入訓練與對戰；逾時／未知不產生確定勝負標籤。**每盤自我對弈實際下到终局**，不以證明提前結束新訓練棋局。
- 每完成 **1,000 盤訓練自我對弈**，完成相關最佳化工作後保存不可覆寫的模型里程碑。可在新實驗調整間隔。評估對局不計入此數量。
- 對外棋譜只存實際落子、開局、終局結果及相關設定／來源，不存機率分布。
- 另保存內部訓練資料與必要策略目標、模型、最佳化器、replay、未完成棋局／工作、RNG 狀態與執行設定。
- 八種棋盤／策略目標變換在訓練時抽樣產生，不儲存八份重複檔案；價值標籤不變。八種等價視角不是八盤獨立對局。
- seed 可指定並保存。重現要求是可載入現有模型、重播棋譜、重新評估及續訓，不必從頭重練；不要求跨裝置或限時搜尋的逐位元一致。
- 使用者手動啟動的訓練每次預設兩小時，可指定 `--hours`；到限／Ctrl+C 安全存檔，下次同命令續訓。
- **使用者要求訓練／評估時間約 80%／20%。** 以實際活動時間累計，每四秒訓練取得一秒評估額度；評估分段並保留未完棋局，額度不足則繼續訓練。未有候選時全數時間訓練，不空等；執行中不可中斷的操作可能短暫超出目標。
- 新實驗預設同時 **64 盤**自我對弈，合併未解根節點的網路推論；快取棋盤，避免每步重播整個歷史。`--parallel` 可明確調整續訓並行量，不刪未完成棋局；`--batch` 是不同的最佳化 minibatch。

## 新舊模型對戰與升級

- 不建立 Elo 聯賽。第一份里程碑模型作為初始比較基準，不宣稱已經很強；之後的新候選挑戰**目前最佳模型**。
- 每次使用 50 組獨立保存的合法開局、每組交換引擎黑白，共 **100 場**。棋子顏色及合法開局歷史不任意反轉。
- 使用者要求加快 gate；工程預設改為雙方每完整回合 **0.25 秒**，每次落子最多使用保存的自我對弈模擬數（預設 64）。多子回合共用時間。模型及對戰設定凍結，評估不訓練模型、不加入 replay。這是短搜尋條件的比較，不代表五秒棋力。
- 未完成評估不阻塞後續模型保存；不可覆寫的模型目錄即候選佇列，輪到該版本時凍結當時的目前最佳作對手。
- 原有未完 gate 不默默改時限或來源碼；`--restart-gate` 明確將原報告完整封存並重新開始，不混合兩種設定的得分。
- 勝／和／敗計 1／0.5／0，候選 **超過 50 分**才取代；平手維持正式版本。100 場必須完整，且保存棋譜經重新驗證。
- 無非法落子／錯誤／非法開局；記錄完整回合時間，任何逾時超過 0.1 秒禁止升級。執行中的 GPU kernel／OS stall 無法強制中斷，不能宣稱硬即時保證。
- 失敗候選、舊正式模型、評估棋譜及結果皆保留。未完成評估可以跨訓練時段續跑。
- 使用者選擇候選對目前最佳的比較方向；100 場、0.25 秒、0.1 秒逾時容忍及原始得分門檻是目前工程預設，不應寫成使用者逐項批准。這不是統計信賴保證、全球 Elo 或已找到理論最強 AI 的證明。對外部強引擎的棋力仍須另測。

## 模組與 Dashboard

- **單一 `engine/` package**：Gomoku、Connect6 是不同棋規配置，不是不同實作。移除 `connect6/`、`gomoku/` 與基底棋盤／子類拆分，不保留轉接 wrapper。
- `engine/game.py`：棋規、合法落子、回合與勝負。一個可設定的 Game，不依賴訓練或瀏覽器。
- training：自我對弈、最佳化、持久資料、模型里程碑、續訓與升級對战。
- CLI：薄入口，直接接受上述棋規旗標，不加入 plugin framework。
- dashboard：本機瀏覽器對戰、模型選擇、訓練進度、loss（總／策略／價值）、候選胜率及和棋計分比較圖。
- 使用者要求最近 **1,000 盤已保存的完整訓練自我對弈**統計：平均落子／回合數、黑白勝率及和棋率，另呈現中位／最短／最長落子數、棋局數／範圍及落子來源。依完成編號選取，不含評估或增強樣本；不足 1,000 盤採現有資料。胜和率以全部棋局為分母，非棋力評估。
- 統計重用現有不可覆寫棋譜，checkpoint 匯出後更新，不另寫訓練統計檔或改搜尋／續訓設定；視窗不刪舊棋譜。回合指單方執子的一回合，包括開局及終局的未滿回合；來源比例不含預設開局子。
- **瀏覽器只呈現成果及對戰，不負責啟動／停止訓練。** 訓練由 CLI 操作；同資料目錄由跨程序鎖保護。
- 不新增前端套件、CDN、帳號、雲端服務或 telemetry；保留鍵盤操作與行動裝置基本可用性。

## 原創性、運算與儲存約束

- 可參考論文與使用一般用途套件（PyTorch／NumPy）；遊戲程式碼原創、權重自行初始化，不複製既有棋類引擎或匯入預訓練 bot 權重。
- 不因新論文就未經驗證替換訓練算法；保留目前策略／價值 PUCT 與獨立驗證的 TSS。未採用的研究筆記已移出精簡文件集。
- **助理不自行啟動持久、長時間 GPU 訓練。** 使用者的預設兩小時 CLI 操作與助理實驗授權不同。後續經使用者明確另行授權，已完成有限 GPU 搜尋比較及臨時 19×19 framework 功能測試；這不授權正式兩小時訓練。結果與測試時間見 [validation](connection-validation.md)；全專案設計圖見 [project architecture](project-architecture.html)。
- 使用者後續明確要求啟動正式 **9×9 自由五子棋**訓練：連五、每回合一子、黑棋開局一子。助理曾依此啟動 CUDA 背景工作，採正常 CLI 的兩小時預設，使用 `data/connect5-9x9-s1-o1-v1/`。使用者隨後要求停止並改為自行啟動；背景工作已安全存檔停止，保留 3,004 盤及 15,936 次更新。後續由使用者自行執行 CLI，助理不自行續跑或用剩餘時間另開實驗。這筆已停止的實際訓練授權與先前測試額度分開。
- 早先的同一筆累計 30 GPU 分鐘額度並未重置，餘額不明。後續兩筆有界測試授權分開計算，不合併或重置舊額度。查論文不增加授權；本次功能驗證已結束，不自動用剩餘額度擴大實驗。
- 預設生成產物上限 **20 GiB**，可調整；空間不足明確停止，保留前次完整存檔，不靜默刪除模型。當前最佳、前一最佳及最新可續訓狀態必須保留。
- Python 環境／套件快取與產物分開計算。付費、系統層級變更、外部上傳或超出授權的執行仍須先取得同意。

## 交付與目前結果

- 已實作以上 CLI、正方形棋規、TSS 引導的終局自我對弈、持久棋譜／內部資料、checkpoint/resume、不可覆寫里程碑、100 場升級流程及成果 Dashboard。
- 驗證包括 CPU 回歸、瀏覽器檢查及另外授權的有界 CUDA 功能測試，皆使用暫存資料目錄；不將測試存檔當成持久已訓練模型，不宣稱已煉出強 AI。最新檢查見 [connection-validation.md](connection-validation.md)。
- 交付時沒有既有訓練 run、棋譜、權重或歷史對戰產物；僅保留原始碼、文件及必要的回歸測試 fixtures。後续使用者啟動的 run 正常保存資料，不由 trainer 自動刪除；生成檔案由 `.gitignore` 排除。
